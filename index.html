About

A real-time lattice-Boltzmann wind tunnel by Sarujan Srikaran The solver runs entirely in "lattice units", and so does the display — see "Reading the units" for how to map u₀ to m/s if you want a physical speed.

The physics: D2Q9 Lattice-Boltzmann with BGK collision plus Smagorinsky-style eddy-viscosity stabilisation. All velocities are shown in lattice units (lu) — the inlet u₀ is cells per step. The stable band is roughly 0.02–0.20 lu; see the "Reading the units" card for the lu → m/s conversion. This is a low-Mach educational LBM solver.

Feedback is appreciated!, The whole source file is hosted in my github account.
